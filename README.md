# Poem World (Art-Nature & Diwan)

A sanctuary of verse, where classical poetry meets the quiet of landscape. An illuminated poetry experience crafted with classical typography, antique frames, parchment textures, subtle scroll parallax and zoom animations, and an interactive Diwan archive.

## ✨ Features

- **Art-Nature Sanctuary**: Classical illuminated design with parchment background textures, SVG fractal noise grain overlay, radial vignette, and custom serif typography (Cormorant Garamond, IM Fell English, IM Fell English SC, Amiri).
- **Parallax & Zoom Effects**: Scroll-driven motion on cutout illustrations and subtle depth scaling on framed antique artwork.
- **Diwan Collection**: Interactive poetry archive featuring Mahmoud Darwish, Emily Dickinson, William Shakespeare, and William Blake.
- **Dynamic Search & Filter**: Filter poems live by poet category chips and instant text search across titles, themes, and verses.
- **Illuminated Frames**: Custom double-rule mat frames with corner ornaments, gilt gold frames, and carved wooden frames.
- **Seamless Navigation**: Client-side hash routing supporting deep links (`#/poems`, `#/poet/[slug]`, `#/poem/[slug]`, `#/about`).

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Runtime & Package Manager**: [Bun](https://bun.sh/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)

## 🚀 Getting Started

### Prerequisites

Ensure [Bun](https://bun.sh/) is installed:

```bash
bun --version
```

### Installation

```bash
bun install
```

### Development Server

Run the development server:

```bash
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

Build for production:

```bash
bun run build
bun run start
```

### Linting

```bash
bun run lint
```
